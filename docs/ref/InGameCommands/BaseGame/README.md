# Asheron's Call Base Game In-Game Command Reference

> Generated from Microsoft KnowledgeBase article Q243622 at <https://jeffpar.github.io/kbarchive/kb/243/Q243622/>.

Markdown versions of the chat commands built into the Asheron's Call client and retail server, kept locally as reference material for the Redox extensions. They need no plugin.
